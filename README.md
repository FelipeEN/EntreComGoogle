# Operação Militar — Demonstração (React)

Projeto organizado em uma estrutura modular **React + Vite + Tailwind CSS**.

## Estrutura de Pastas

```text
projeto-react-operacao-v2/
├── index.html
├── package.json
├── postcss.config.js
├── tailwind.config.js
├── vite.config.js
├── README.md
└── src/
    ├── main.jsx
    ├── App.jsx
    ├── components/
    │   ├── HudBackground.jsx
    │   ├── HeroIntro.jsx
    │   ├── LoginView.jsx
    │   └── ProfileView.jsx
    └── styles/
        └── tactical.css
```

## Como executar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
